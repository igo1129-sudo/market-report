# 每日全球股指自动速览

每天早上 6:50（新加坡时间）自动从 Yahoo Finance 抓取指数收盘价及涨跌幅，
生成一份网页报告 `report.html`。整个流程跑在 GitHub 的免费云端服务器上，
你的电脑不需要开机。

## 覆盖的指数

| 分组 | 指数 |
|---|---|
| 欧美 | 道琼斯工业、标普500、纳斯达克综指、法国CAC40、德国DAX、英国富时100 |
| 新加坡 | 新加坡海峡指数 |
| 港股 | 恒生指数、恒生国企、恒生科技 |
| A股 | 上证指数、深证成指、沪深300、中证500、创业板指、科创50 |

代码文件里每个指数对应一个 Yahoo Finance 代码（如 `^DJI`、`000300.SS`），
如果你需要增减指数，直接改 `fetch_indices.py` 里的 `GROUPS` 列表即可。

## 部署步骤（一次性，约10分钟）

1. **建一个 GitHub 仓库**（如果没有 GitHub 账号，先免费注册一个）。
   新建一个仓库，比如叫 `market-report`。

2. **把这个文件夹里的所有文件上传到仓库**（保留目录结构，
   `.github/workflows/daily.yml` 这个路径必须原样保留）。

3. **打开仓库的 Settings → Actions → General**，确认 "Workflow permissions"
   设置为 "Read and write permissions"（这样脚本才能自动提交更新后的网页）。

4. **打开仓库的 Settings → Pages**，Source 选择 `Deploy from a branch`，
   分支选 `main`，目录选 `/ (root)`。保存后 GitHub 会给你一个网址，
   形如 `https://你的用户名.github.io/market-report/report.html`，
   这个链接就是你每天早上要看的报告页面，可以直接收藏或做成手机主屏快捷方式。

5. **测试一下**：打开仓库的 Actions 标签页，选择 "Daily Market Snapshot"，
   点击 "Run workflow" 手动跑一次，确认几分钟后 `report.html` 有更新、
   数值看起来合理。

完成以上步骤后，脚本会在每个工作日新加坡时间 6:50 自动运行，无需你再操作。

## 关于"权威数据"和"不出错"，几点如实说明

这几点很重要，希望你部署前心里有数：

- **Yahoo Finance 是免费公开数据源，不是彭博/Wind那个级别的权威数据商**。
  多数主流指数（道指、标普、恒指、沪深300等）数据质量稳定，但小众指数
  （比如中证500、科创50）偶尔会出现某天取不到数据的情况。脚本已经做了
  容错处理：某个指数抓取失败时，页面会显示"数据缺失"并在页面底部列出
  失败清单，而不会用错误数字冒充，也不会让整个报告崩掉。

- **6:50 这个时间点，A股、港股、新加坡市场都还没开盘**（A股9:30开盘，
  港股/新加坡9:00-9:30开盘），所以这几个板块显示的是它们上一个完整
  交易日的收盘表现，不是当天实时数据——这和你截图里A股板块显示
  "0.00%"（开盘前无新变化）是同一个逻辑。

- **GitHub Actions 的定时任务不保证分秒不差**，官方说明是可能有几分钟到
  十几分钟的延迟（尤其在使用高峰期）。如果你需要精确到分钟的执行，
  云端免费方案很难做到，需要用付费的专业数据终端配合服务器定时任务。

- 我在这个环境里没有网络权限访问 Yahoo Finance，所以**没有条件端到端
  跑一遍脚本验证每个代码都能正常取到数据**——代码本身逻辑是对的，
  股指代码也逐一核实过，但建议你部署后先手动跑一次（见上面步骤5），
  看看有没有指数在失败清单里，再决定要不要用来支撑正式工作输出。
